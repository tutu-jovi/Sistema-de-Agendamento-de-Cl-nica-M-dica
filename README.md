 # Sistema de Agendamento - Clínica Médica Vida Saudável
> Sistema de Agendamento e Consulta Clínica/Médica
> Projeto desenvolvido em JavaScript para organizar o agendamento de consultas da Clínica Médica Vida Saudável.

> # Objetivo
> Criar um sistema interativo no terminal para cadastrar, listar e buscar consultas.
> 
> # Funcionalidades
> - Cadastrar consulta com paciente, médico, data e horário
> - Listar todas as consultas cadastradas
> - Buscar consultas pelo nome do paciente
> - Encerrar o sistema pelo menu


> #Tecnologias utilizadas
> - JavaScript

> 
> # Menu
> 1. Cadastrar consulta
> 2. Listar consultas
> 3. Buscar consulta por paciente
> 4. Sair
